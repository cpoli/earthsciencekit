earthsciencekit.climate.absorbed_solar(solar_constant, albedo)[source]#

Planetary mean absorbed sunlight.

Sphere geometry and reflection set the global mean solar input.

Parameters:

  • solar_constant (float or array_like) – W/m^2; constraint: nonnegative.

  • albedo (float or array_like) – 1; constraint: fraction.

Returns:

Model value [W/m^2]. Scalar input returns a NumPy scalar; arrays broadcast.

Return type:

numpy scalar or ndarray

Notes

Global mean rather than local insolation; fixed bolometric albedo. Equation: solar_constant * (1 - albedo) / 4. Invalid, empty, nonreal or nonfinite inputs raise ValueError. NumPy broadcasting applies; singular and overflowing outputs raise ValueError.

earthsciencekit.climate.daily_insolation(solar_constant, latitude, declination, distance_ratio)[source]#

Daily-mean top-of-atmosphere insolation.

Latitude, solar declination and Earth-Sun distance set the sunlight a latitude receives over a day.

Parameters:

  • solar_constant (float or array_like) – W/m^2 at the mean Earth-Sun distance; constraint: nonnegative.

  • latitude (float or array_like) – rad; constraint: closed interval [-pi/2, pi/2].

  • declination (float or array_like) – rad; constraint: closed interval [-pi/2, pi/2].

  • distance_ratio (float or array_like) – 1, mean over actual Earth-Sun distance; constraint: positive.

Returns:

Model value [W/m^2]. Scalar input returns a NumPy scalar; arrays broadcast.

Return type:

numpy scalar or ndarray

Notes

Declination fixed over the day, no atmosphere; the sunset hour angle h0 is clipped for polar day and night. Equation: solar_constant * distance_ratio**2 / pi * (h0 * sin(phi) * sin(delta) + cos(phi) * cos(delta) * sin(h0)) with phi = latitude, delta = declination and h0 = arccos(clip(-tan(phi) * tan(delta), -1, 1)). Invalid, empty, nonreal or nonfinite inputs raise ValueError. NumPy broadcasting applies; singular and overflowing outputs raise ValueError.

earthsciencekit.climate.effective_temperature(absorbed_flux, emissivity)[source]#

Radiative equilibrium temperature.

Stefan-Boltzmann emission links an energy balance to temperature.

Parameters:

  • absorbed_flux (float or array_like) – W/m^2; constraint: nonnegative.

  • emissivity (float or array_like) – 1; constraint: open fraction.

Returns:

Model value [W/m^2]. Scalar input returns a NumPy scalar; arrays broadcast.

Return type:

numpy scalar or ndarray

Notes

Single emitting level in equilibrium; not the surface temperature of a greenhouse atmosphere. Equation: (absorbed_flux / (emissivity * SIGMA_SB))**0.25. Invalid, empty, nonreal or nonfinite inputs raise ValueError. NumPy broadcasting applies; singular and overflowing outputs raise ValueError.

earthsciencekit.climate.equilibrium_solar_constant(temperature, emissivity, cold_albedo, warm_albedo, transition_temperature, width)[source]#

Solar constant that holds a planet with ice-albedo feedback at a given temperature.

Inverting the energy balance traces every equilibrium, including the unstable branch between a warm and an ice-covered state.

Parameters:

  • temperature (float or array_like) – K; constraint: positive.

  • emissivity (float or array_like) – 1; constraint: open fraction.

  • cold_albedo (float or array_like) – 1; constraint: fraction below one.

  • warm_albedo (float or array_like) – 1; constraint: fraction.

  • transition_temperature (float or array_like) – K; constraint: positive.

  • width (float or array_like) – K; constraint: positive.

Returns:

Model value [W/m^2]. Scalar input returns a NumPy scalar; arrays broadcast.

Return type:

numpy scalar or ndarray

Notes

Zero-dimensional greybody balance with the ice_albedo closure; equilibria with a negative slope dS/dT are unstable. Equation: 4 * emissivity * SIGMA_SB * temperature**4 / (1 - albedo), with albedo from ice_albedo. Invalid, empty, nonreal or nonfinite inputs raise ValueError. NumPy broadcasting applies; singular and overflowing outputs raise ValueError.

earthsciencekit.climate.greenhouse_surface_temperature(absorbed_flux, layer_emissivity)[source]#

Surface temperature under one absorbing atmospheric layer.

A layer that absorbs and re-emits infrared returns part of the surface emission and warms the ground.

Parameters:

  • absorbed_flux (float or array_like) – W/m^2; constraint: nonnegative.

  • layer_emissivity (float or array_like) – 1; constraint: fraction.

Returns:

Model value [K]. Scalar input returns a NumPy scalar; arrays broadcast.

Return type:

numpy scalar or ndarray

Notes

Blackbody surface, a grey isothermal layer transparent to sunlight; the layer temperature is the surface temperature over 2**0.25. Equation: (2 * absorbed_flux / ((2 - layer_emissivity) * SIGMA_SB))**0.25. Invalid, empty, nonreal or nonfinite inputs raise ValueError. NumPy broadcasting applies; singular and overflowing outputs raise ValueError.

earthsciencekit.climate.gregory_regression(temperature_change, imbalance)[source]#

Forcing and feedback from a regression of imbalance on warming.

In a run with constant forcing, the top-of-atmosphere imbalance falls linearly with warming, so a straight-line fit gives both.

Parameters:

  • temperature_change (array_like, shape (n,), n >= 2) – K; constraint: real, not all equal.

  • imbalance (array_like, shape (n,)) – W/m^2, net downward top-of-atmosphere flux; constraint: real.

Returns:

[forcing, restoring]: the intercept [W/m^2] and minus the slope [W/(m^2 K)] of the least-squares line.

Return type:

numpy.ndarray, shape (2,)

Notes

Assumes N = F - lambda T with constant F and lambda; equilibrium warming is forcing / restoring. Equation: imbalance = forcing - restoring * temperature_change (ordinary least squares). Invalid, empty, nonreal or nonfinite inputs raise ValueError.

earthsciencekit.climate.methane_forcing(concentration, reference_concentration, nitrous_oxide)[source]#

Methane radiative forcing (Myhre et al. 1998).

Methane forcing grows as a square root of concentration, less the band it shares with nitrous oxide.

Parameters:

  • concentration (float or array_like) – ppb; constraint: positive.

  • reference_concentration (float or array_like) – ppb; constraint: positive.

  • nitrous_oxide (float or array_like) – ppb, reference N2O concentration; constraint: positive.

Returns:

Model value [W/m^2]. Scalar input returns a NumPy scalar; arrays broadcast.

Return type:

numpy scalar or ndarray

Notes

Simplified fit to line-by-line calculations, valid near present-day concentrations; with f(M, N) = 0.47 * log(1 + 2.01e-5 * (M * N)**0.75 + 5.31e-15 * M * (M * N)**1.52). Equation: 0.036 * (sqrt(M) - sqrt(M0)) - (f(M, N0) - f(M0, N0)), with M = concentration, M0 = reference_concentration and N0 = nitrous_oxide. Invalid, empty, nonreal or nonfinite inputs raise ValueError. NumPy broadcasting applies; singular and overflowing outputs raise ValueError.

earthsciencekit.climate.radiative_convective_temperature(height, effective_temperature, lapse_rate, emission_height)[source]#

Radiative-convective equilibrium temperature profile.

Convection holds the troposphere at a fixed lapse rate below a radiatively balanced stratosphere.

Parameters:

  • height (float or array_like) – m above the surface; constraint: nonnegative.

  • effective_temperature (float or array_like) – K; constraint: positive.

  • lapse_rate (float or array_like) – K/m; constraint: positive.

  • emission_height (float or array_like) – m; constraint: nonnegative.

Returns:

Model value [K]. Scalar input returns a NumPy scalar; arrays broadcast.

Return type:

numpy scalar or ndarray

Notes

Grey optically thin stratosphere at the skin temperature effective_temperature / 2**0.25; the troposphere passes through effective_temperature at emission_height, so the surface is effective_temperature + lapse_rate * emission_height. Equation: np.maximum(effective_temperature + lapse_rate * (emission_height - height), effective_temperature / 2**0.25). Invalid, empty, nonreal or nonfinite inputs raise ValueError. NumPy broadcasting applies; singular and overflowing outputs raise ValueError.

earthsciencekit.climate.red_noise_spectrum(frequency, forcing_spectrum, restoring, areal_heat_capacity)[source]#

Temperature spectrum of a one-box climate driven by white noise.

Heat capacity integrates random weather forcing into slow red-noise climate variability.

Parameters:

  • frequency (float or array_like) – Hz; constraint: real.

  • forcing_spectrum (float or array_like) – W^2/(m^4 Hz), two-sided; constraint: nonnegative.

  • restoring (float or array_like) – W/(m^2 K); constraint: positive.

  • areal_heat_capacity (float or array_like) – J/(m^2 K); constraint: positive.

Returns:

Model value [K^2/Hz], two-sided. Scalar input returns a NumPy scalar; arrays broadcast.

Return type:

numpy scalar or ndarray

Notes

Linear C dT/dt = F - lambda T with white-noise F; integrating over all frequencies gives the variance forcing_spectrum / (2 * restoring * areal_heat_capacity). Equation: forcing_spectrum / (restoring**2 + (2 * np.pi * frequency * areal_heat_capacity)**2). Invalid, empty, nonreal or nonfinite inputs raise ValueError. NumPy broadcasting applies; singular and overflowing outputs raise ValueError.

Integrate a linear one-box climate energy balance.

  • restoring (float) – Positive scalar net restoring coefficient [W/(m^2 K)].

  • areal_heat_capacity (float) – Positive scalar effective heat capacity [J/(m^2 K)].

  • time (array_like) – Nonnegative strictly increasing sampled times [s].

Returns:

TimeSeries

earthsciencekit.climate.step_temperature(forcing, restoring, areal_heat_capacity, time)[source]#

Transient one-box warming.

A step forcing exposes the lag between forcing and temperature adjustment.

Parameters:

  • forcing (float or array_like) – W/m^2; constraint: real.

  • restoring (float or array_like) – W/(m^2 K); constraint: positive.

  • areal_heat_capacity (float or array_like) – J/(m^2 K); constraint: positive.

  • time (float or array_like) – s; constraint: nonnegative.

Returns:

Model value [W/m^2]. Scalar input returns a NumPy scalar; arrays broadcast.

Return type:

numpy scalar or ndarray

Notes

Zero initial anomaly and constant parameters; no deep-ocean exchange. Equation: forcing / restoring * (-np.expm1(-restoring * time / areal_heat_capacity)). Invalid, empty, nonreal or nonfinite inputs raise ValueError. NumPy broadcasting applies; singular and overflowing outputs raise ValueError.
