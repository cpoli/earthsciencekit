earthsciencekit.atmosphere.barometer_column_height(pressure, liquid_density, gravity)[source]#

Liquid barometer column height.

The weight of a liquid column balances the pressure of the air above it.

Parameters:

  • pressure (float or array_like) – Pa; constraint: nonnegative.

  • liquid_density (float or array_like) – kg/m^3; constraint: positive.

  • gravity (float or array_like) – m/s^2; constraint: positive.

Returns:

Model value [m]. Scalar input returns a NumPy scalar; arrays broadcast.

Return type:

numpy scalar or ndarray

Notes

Incompressible liquid with a vacuum above the column; vapour pressure and capillarity are neglected. Equation: pressure / (liquid_density * gravity). Invalid, empty, nonreal or nonfinite inputs raise ValueError. NumPy broadcasting applies; singular and overflowing outputs raise ValueError.

earthsciencekit.atmosphere.barometric_pressure(surface_pressure, height, temperature, gravity)[source]#

Isothermal barometric profile.

Vertical pressure structure follows from hydrostatic balance and the gas law.

Parameters:

  • surface_pressure (float or array_like) – Pa; constraint: positive.

  • height (float or array_like) – m; constraint: real.

  • temperature (float or array_like) – K; constraint: positive.

  • gravity (float or array_like) – m/s^2; constraint: positive.

Returns:

Model value [kg/m^3]. Scalar input returns a NumPy scalar; arrays broadcast.

Return type:

numpy scalar or ndarray

Notes

Isothermal column; signed height is relative to the reference level. Equation: surface_pressure * np.exp(-gravity * height / (R_DRY_AIR * temperature)). Invalid, empty, nonreal or nonfinite inputs raise ValueError. NumPy broadcasting applies; singular and overflowing outputs raise ValueError.

earthsciencekit.atmosphere.simulate_barotropic_vorticity(initial_vorticity, time, beta, spacing)[source]#

Integrate the barotropic vorticity equation on a periodic beta plane.

Parameters:

  • initial_vorticity (array_like, shape (ny, nx), ny, nx >= 4) – Relative vorticity [1/s] on an equally spaced doubly periodic grid, rows northward and columns eastward.

  • time (array_like) – Strictly increasing nonnegative output times [s]. Initial state belongs to the first supplied time; values need not start at zero.

  • beta (float) – Nonnegative scalar northward gradient of the Coriolis parameter [1/(m s)].

  • spacing (float) – Positive scalar grid spacing [m], the same in both directions.

Returns:

Relative vorticity at each grid point [1/s], flattened row by row. Columns are labeled cell_<row>_<column>.

Return type:

TimeSeries

Notes

Solves d(zeta)/dt + J(psi, zeta) + beta * d(psi)/dx = 0 with laplacian(psi) = zeta. Derivatives are pseudo-spectral (FFT) with the two-thirds dealiasing rule, and integrators.integrate_ode steps in time. The domain mean of vorticity is removed and conserved; energy and enstrophy are conserved up to the time-stepping error. A single Fourier mode is an exact Rossby wave. There is no forcing, friction, divergence or sphere.

earthsciencekit.atmosphere.simulate_dry_ascent(initial_temperature, initial_pressure, vertical_speed, time)[source]#

Follow an ideal dry parcel along a hydrostatic constant-speed ascent.

Parameters:

  • initial_temperature (float) – Positive scalar initial temperature [K].

  • initial_pressure (float) – Positive scalar initial pressure [Pa].

  • vertical_speed (float) – Finite scalar vertical velocity [m/s], positive upward.

  • time (array_like) – Nonnegative strictly increasing sampled times [s].

Returns:

Parcel temperature [K] and pressure [Pa].

Return type:

TimeSeries

Notes

Dry lapse and hydrostatic pressure equations use constant standard gravity and dry-air heat capacity. Potential temperature should remain constant. The parcel is unsaturated; condensation and environmental entrainment are excluded. Reject trajectories whose predicted temperature reaches zero.

Troposphere-stratosphere temperature profile.

Temperature falls with height up to the tropopause and stays constant above it.

  • height (float or array_like) – m; constraint: nonnegative.

  • surface_temperature (float or array_like) – K; constraint: positive.
