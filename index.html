earthsciencekit: Earth-System Models in Python#

EarthScienceKit makes the equations behind 7 Earth-science domains computable, inspectable and visualizable. Choose a domain to explore its history, run its examples and inspect its API. NumPy and SciPy provide the numerical foundations; this package connects them to Earth-system concepts.

Start here#

Quickstart introduces the API. Numerical methods and sampled results explains sampled histories and solver choices. The model guides give equations, units, conventions and applicability limits. Validation policy documents the evidence behind this release and Scope and limitations describes its scope.

import numpy as np
from earthsciencekit.climate import simulate_one_box
from earthsciencekit.units import convert

time = convert(np.linspace(0, 100, 201), "year", "s")
result = simulate_one_box(4, 1.2, 2e8, time)
print(result.summary())
figure, axes = result.plot()
