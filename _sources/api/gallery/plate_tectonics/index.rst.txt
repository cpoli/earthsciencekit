Plate Tectonics examples
========================

One executed example per breakthrough in :doc:`/history/plate_tectonics_breakthroughs`,
in chronological order, each with an asserted check of the result it shows.
Download the Python source or notebook from each page. :doc:`/guides/plate_tectonics` records units and
limits; all examples use deterministic synthetic inputs and require no downloads.
